# 연산 JSON 뷰어 사용 메뉴얼 계획서

## 목적

팀원이 `연산 JSON 뷰어`를 배포본으로 사용할 때, 화면을 벗어나지 않고 필요한 기능과 오류 의미를 바로 확인할 수 있는 팝업형 메뉴얼을 만든다.

메뉴얼은 일반적인 JSON 설명서가 아니라, 현재 `index.html` 화면에 표시되는 실제 용어와 작동 방식을 기준으로 작성한다.

## 기본 방향

- 상단 `연산 JSON 뷰어` 제목과 `폴더 선택` 버튼 사이에 파란색 원형 `?` 버튼을 둔다.
- `?` 버튼을 누르면 스크롤 가능한 팝업 메뉴얼을 연다.
- 메뉴얼은 새 페이지로 이동하지 않는다.
- 문구는 실제 화면의 버튼명, 상태 문구, 오류 표현을 그대로 사용한다.
- 텍스트만 나열하지 않고 색상 배지와 강조 박스를 사용한다.
- `문의 전 확인사항` 섹션은 만들지 않는다.
- 메뉴얼 최상단에는 대략적인 사용 흐름을 먼저 보여주는 요약 카드를 둔다.
- 세부 메뉴얼은 요약 카드 아래에 폴딩 섹션으로 배치한다.

## 메뉴얼 표시 구조

1. 최상단 요약 카드
2. 세부 메뉴얼 폴딩 영역
3. 색상 배지와 경고 박스

## 최상단 요약 카드

### 목적

메뉴얼을 열었을 때 처음 사용하는 팀원이 전체 사용 흐름을 바로 이해하도록 한다. 긴 설명을 먼저 보여주지 않고, `폴더 선택`부터 `오류 확인`까지의 흐름을 한눈에 보여준다.

### 카드 문구

연산 JSON 뷰어는 작업 폴더를 불러온 뒤, 왼쪽에서 문항을 고르고 오른쪽에서 내용과 이미지를 확인하는 도구입니다.

### 사용 흐름

`폴더 선택` → `문항 선택` → `내용·이미지 확인` → `JSON/이미지 수정` → `다시 읽기` → `오류 확인`

### 다시 읽기 강조 문구

작업 중 JSON 파일이나 이미지 파일을 수정한 경우, `다시 읽기`를 누르면 변경된 JSON 내용과 이미지 파일을 다시 불러와 화면에서 바로 확인할 수 있습니다.

### 요약 카드 시각 표현

- 배경: 옅은 파란색
- 제목: `처음 사용하는 순서`
- 흐름: 단계형 배지 또는 가로 플로우
- `다시 읽기`: 파란색 강조 배지
- `오류 확인`: 빨강 강조 배지
- `내용·이미지 확인`: 초록 강조 배지

## 세부 메뉴얼 폴딩 구성

요약 카드 아래에는 세부 메뉴얼을 폴딩 형태로 배치한다. 기본 상태는 모두 접어 두거나, 첫 번째 `빠른 시작`만 펼친 상태로 둘 수 있다.

권장 기본값은 `빠른 시작`만 펼침이다. 사용자는 첫 안내를 바로 읽고, 필요한 항목만 추가로 펼쳐 볼 수 있다.

세부 폴딩 항목은 아래 순서로 둔다.

1. `빠른 시작`
2. `화면 구성`
3. `문항 확인 방법`
4. `검색과 필터`
5. `이미지 확인`
6. `오류와 경고`

<details open>
<summary>1. 빠른 시작</summary>

### 본문

`폴더 선택`을 눌러 연산 JSON 파일과 이미지 파일이 들어있는 폴더를 선택합니다. 폴더를 선택하면 상단에 `파일 N개 / section N개 / 문항 N개 / 이미지 N개`가 표시되고, 왼쪽에는 JSON 파일, section, 문항 번호가 트리 형태로 나타납니다.

왼쪽에서 문항을 선택하면 오른쪽에서 `문제`, `choices`, `answer_type`, `answer`, `해설`을 확인할 수 있습니다.

### 안내 강조

전달받은 작업 폴더의 구조를 유지한 상태로 사용해 주세요. JSON 안의 `[img: 파일명]` 정보와 실제 이미지 파일이 연결되어야 이미지가 정상 표시됩니다.

### 빠른 순서

1. `폴더 선택`을 누릅니다.
2. 연산 JSON 파일과 이미지 파일이 들어있는 작업 폴더를 선택합니다.
3. 왼쪽 목록에서 JSON 파일, section, 문항 번호를 차례로 확인합니다.
4. 확인할 문항을 클릭합니다.
5. 오른쪽 상세 화면에서 문제, 보기, 정답, 해설, 이미지 표시 상태를 확인합니다.

</details>

<details>
<summary>2. 화면 구성</summary>

### 본문

화면은 상단 작업 영역, 왼쪽 문항 목록, 오른쪽 상세 화면으로 나뉩니다.

| 항목 | 설명 |
|---|---|
| `폴더 선택` | JSON 파일과 이미지 파일이 들어있는 폴더를 처음 불러옵니다. |
| `최근 폴더` | 이전에 열었던 폴더 목록을 다시 엽니다. 브라우저 권한이 필요할 수 있습니다. |
| `다시 읽기` | 현재 폴더를 다시 불러와 JSON 파일 수정, 이미지 파일 추가, 이미지 파일 수정, 이미지 파일 교체 내용을 갱신해서 확인합니다. 작업 중 파일을 고친 뒤 화면에 바로 반영하고 싶을 때 사용합니다. |
| 상단 개수 표시 | `파일 N개 / section N개 / 문항 N개 / 이미지 N개` 형식으로 현재 불러온 데이터를 보여줍니다. |
| 왼쪽 목록 | JSON 파일, section, 문항 번호 순서로 표시됩니다. |
| 오른쪽 상세 화면 | 선택한 문항의 `문제`, `choices`, `answer_type`, `answer`, `해설`을 보여줍니다. |

### `최근 폴더`와 `다시 읽기` 안내

`최근 폴더`는 이전에 열었던 폴더를 다시 선택하는 기능입니다. 브라우저에 따라 폴더 기억을 지원하지 않을 수 있으며, 권한이 끊기면 `최근 폴더 권한이 필요합니다. 폴더 선택을 다시 눌러 주세요.`가 표시될 수 있습니다.

`다시 읽기`는 현재 기억된 폴더를 다시 불러오는 기능입니다. JSON이나 이미지 파일을 수정한 뒤 화면에 반영하고 싶을 때 사용합니다.

</details>

<details>
<summary>3. 문항 확인 방법</summary>

### 본문

왼쪽 목록에서 JSON 파일명을 펼치면 section 목록이 보입니다. section을 펼치면 `1번`, `2번` 같은 문항 번호가 표시됩니다. 문항을 클릭하면 오른쪽 상세 화면에서 해당 문항을 확인합니다.

### 상세 화면 항목

| 항목 | 의미 |
|---|---|
| `문제` | JSON의 `question.stem` 내용입니다. |
| `blocks` | JSON의 `question.blocks`가 있을 때 표시됩니다. |
| `choices` | 선택지입니다. ①, ②, ③ 형식으로 표시됩니다. |
| `answer_type` | 정답 유형입니다. |
| `answer` | 정답 값입니다. |
| `해설` | 문항 해설입니다. |
| `image_edit_notes` | 이미지 작업 메모입니다. 기본은 접힌 상태이며 `펼치기`로 확인합니다. |
| `JSON 원문 보기 ON/OFF` | 현재 문항의 원본 JSON을 그대로 확인합니다. |

### 이동 기능

- `이전문항`: 현재 필터와 검색 결과 안에서 이전 문항으로 이동합니다.
- `다음문항`: 현재 필터와 검색 결과 안에서 다음 문항으로 이동합니다.
- `Alt+Q`: 이전 문항으로 이동합니다.
- `Alt+W`: 다음 문항으로 이동합니다.

</details>

<details>
<summary>4. 검색과 필터</summary>

### `문항 찾기`

`문항 찾기`에는 파일명, section, 문항 번호, 문제, blocks, choices, answer, 해설, image_edit_notes에 포함된 내용을 검색할 수 있습니다.

LaTeX 명령을 찾을 때는 `\frac`, `₩frac`, `\dfrac`, `₩dfrac` 같은 입력도 사용할 수 있습니다.

### 필터 색상 규칙

| 색상 | 필터 | 설명 |
|---|---|---|
| 초록 | `img 있는 문항` | `[img: 파일명]` 또는 `image_edit_notes`가 있는 문항만 표시합니다. |
| 보라 | `blocks 있는 문항` | `question.blocks`가 있는 문항만 표시합니다. |
| 노랑 | `이미지 파일을 찾을 수 없는 문항` | JSON에는 이미지 참조가 있지만 실제 이미지 파일을 찾지 못한 문항만 표시합니다. |
| 빨강 | `latex 오류있는 문항` | `$`, `$$`, `\(`, `\)`, `\[`, `\]` 구분자 개수가 맞지 않는 문항만 표시합니다. |

### 팝업 표현 제안

- 초록 배지: `img 있는 문항`
- 보라 배지: `blocks 있는 문항`
- 노랑 배지: `이미지 파일을 찾을 수 없는 문항`
- 빨강 배지: `latex 오류있는 문항`

필터 버튼이 켜지면 실제 화면처럼 필터명 옆에 색상 점을 함께 보여준다.

</details>

<details>
<summary>5. 이미지 확인</summary>

### 본문

이미지는 JSON 본문 안의 `[img: 파일명]` 형식을 기준으로 표시됩니다. 뷰어는 선택한 폴더 안의 `png`, `jpg`, `jpeg`, `webp`, `gif` 파일을 찾아 이미지 목록을 만들고, JSON에 적힌 이미지 파일명과 연결합니다.

### 이미지 기능

| 기능 | 설명 |
|---|---|
| `이미지 표시` | 체크하면 `[img: 파일명]` 위치에 이미지를 보여줍니다. 해제하면 원문 텍스트로 봅니다. |
| `이미지 크기` | 표시되는 이미지 크기를 100px부터 500px까지 조절합니다. |
| `이미지 없음: 파일명` | JSON에는 이미지가 적혀 있지만 실제 파일을 찾지 못한 상태입니다. |
| `파일명 복사` | `image_edit_notes`의 image 값에서 확장자를 제외한 파일명을 복사합니다. |

### 주의 강조

이미지가 보이지 않을 때는 먼저 파일명이 정확한지 확인해 주세요. 띄어쓰기, 확장자, 폴더 위치가 달라지면 `이미지 없음: 파일명`으로 표시될 수 있습니다.

### 색상 표현 제안

- `이미지 없음: 파일명`은 노랑 배지 또는 노랑 안내 박스로 표시한다.
- 이미지 관련 기능은 초록 계열 배지를 사용한다.
- `이미지 크기`는 실제 범위인 `100px-500px`를 함께 표시한다.

</details>

<details>
<summary>6. 오류와 경고</summary>

### 본문

상단에 `오류 N개`가 표시되면 JSON 문법 오류 또는 LaTeX 경고가 있다는 뜻입니다. `오류 N개`를 클릭하면 `오류만 보기 ON / 오류 N개` 상태가 되며, 오류가 있는 항목만 왼쪽 목록에 표시됩니다.

### 오류 유형

| 표시 | 의미 | 확인 방법 |
|---|---|---|
| `JSON 첫 번째 감지 오류` | JSON 파일을 파싱하지 못했습니다. | 오른쪽의 `오류 메시지`, `줄`, `칸`, `주변 원문`을 확인합니다. |
| `JSON 최상위 값은 객체여야 합니다.` | JSON 최상단이 객체 형식이 아닙니다. | 파일 구조가 `{ ... }` 형태인지 확인합니다. |
| `sections 배열을 찾을 수 없습니다.` | JSON에 `sections` 배열이 없습니다. | 생성된 JSON 구조를 확인합니다. |
| `이미지 파일을 찾을 수 없음: 파일명` | 이미지 참조는 있지만 파일 연결에 실패했습니다. | 실제 이미지 파일 위치와 파일명을 확인합니다. |
| `$ 구분자 개수가 맞지 않습니다.` | LaTeX 인라인 수식 구분자가 맞지 않습니다. | 해당 문항의 수식 기호를 확인합니다. |
| `\(` `\)` `구분자 개수가 맞지 않습니다.` | LaTeX 괄호형 수식 구분자가 맞지 않습니다. | 여는 기호와 닫는 기호를 확인합니다. |
| `\[` `\]` `구분자 개수가 맞지 않습니다.` | LaTeX 블록 수식 구분자가 맞지 않습니다. | 여는 기호와 닫는 기호를 확인합니다. |

### JSON 오류 안내 문구

JSON 파서는 파일당 첫 번째로 감지한 문법 오류만 확정 표시합니다. 이 오류를 수정한 뒤 `다시 읽기`를 누르면 다음 오류가 표시될 수 있습니다.

### 색상 표현 제안

- `오류 N개`: 빨강 배지
- `오류만 보기 ON / 오류 N개`: 빨강 배지와 옅은 빨강 배경
- `JSON 첫 번째 감지 오류`: 빨강 경고 박스
- `이미지 파일을 찾을 수 없음: 파일명`: 노랑 배지
- LaTeX 구분자 오류: 빨강 점 또는 빨강 라벨

</details>

## 팝업 UI 계획

### 버튼

- 위치: `연산 JSON 뷰어` 제목과 `폴더 선택` 사이
- 형태: 파란색 원형 버튼
- 텍스트: `?`
- title: `사용 메뉴얼 보기`
- aria-label: `사용 메뉴얼 열기`

### 팝업

- 제목: `연산 JSON 뷰어 사용 메뉴얼`
- 닫기 버튼: 우측 상단 `×`
- 닫기 동작: 닫기 버튼, 바깥 영역 클릭, `Esc`
- 내부 스크롤: 메뉴얼 본문 영역만 스크롤
- 모바일: 화면 폭에 맞춰 여백을 줄이고, 팝업 높이는 화면 안에 유지

### 시각 스타일

- 전체 배경은 흰색 또는 기존 UI와 맞는 밝은 배경
- 섹션 제목은 짧고 굵게 표시
- 표는 가볍게 구분선만 사용
- 필터와 오류 설명에는 실제 화면과 맞는 색상 점, 배지, 안내 박스를 사용

## 구현 체크리스트

1. `?` 도움말 버튼을 상단에 추가한다.
2. 메뉴얼 팝업 HTML을 추가한다.
3. 팝업 전용 CSS를 추가한다.
4. 색상 배지, 경고 박스, 필터 점 스타일을 추가한다.
5. 열기, 닫기, 바깥 클릭, `Esc` 닫기 스크립트를 추가한다.
6. 기존 `최근 폴더` 메뉴와 `필터` 메뉴 닫기 동작과 충돌하지 않는지 확인한다.
7. 좁은 화면에서도 팝업이 화면 밖으로 넘치지 않는지 확인한다.
8. 기존 JSON 로딩, 검색, 필터, 이미지 표시 기능이 그대로 동작하는지 확인한다.
