# 메인페이지 개편 구상

## 목적

기존 `연산 JSON 뷰어`를 바로 문항뷰어 화면으로 시작하지 않고, 세 가지 기능으로 진입할 수 있는 메인페이지를 먼저 제공한다.

```text
[메인페이지]
├ [문항뷰어]
├ [section 뷰어]
└ [통계]
```

## 기본 방향

- 메인페이지는 사용자가 기능을 선택하는 진입 화면이다.
- 기존 문항뷰어의 도구형 UI 느낌을 유지한다.
- 과한 랜딩페이지 스타일보다 실제 작업 도구에 가까운 단순한 화면을 우선한다.
- 현재 뷰어 상단의 이미지 패널과 도구줄 구성은 최대한 유지한다.
- 각 페이지로 이동해도 상단 공통 헤더는 유지하고, 왼쪽 제목 텍스트만 현재 페이지명으로 바꾼다.
- 도움말 내용은 나중에 실제 기능에 맞게 수정한다.

## 화면 구성

중앙 정렬된 화면을 기준으로 아래 순서로 배치한다.

```text
연산 JSON 뷰어

[?] [폴더 선택] [▼ section 선택] [다시 읽기]

[문항뷰어] [section 뷰어] [통계]
```

단, 실제 구현 시 상단 도구줄은 기존 뷰어처럼 화면 상단에 고정된 공통 헤더로 둘 수 있다.

### 제목

- 텍스트: `연산 JSON 뷰어`
- 위치: `폴더 선택` 버튼이 있는 도구줄 위쪽 가운데
- 역할: 메인페이지의 서비스명 또는 화면 제목

### 도구줄

기존 작업물의 상단 도구줄 느낌을 유지한다.

- 파란색 `?` 도움말 버튼
- `폴더 선택` 버튼
- section 선택 드롭다운
- 기능 페이지의 `다시 읽기` 버튼

메인페이지에서는 `다시 읽기` 버튼을 숨기고, 화면 이동 버튼을 누를 때 자동 다시 읽기를 시도한다.

### 공통 헤더 제목 규칙

상단 헤더의 왼쪽 제목 영역은 홈 아이콘과 현재 페이지 제목으로 구성한다.

- 집 모양 홈 아이콘을 제목 왼쪽에 둔다.
- 홈 아이콘을 누르면 메인페이지로 이동한다.
- 현재 페이지 제목은 페이지에 맞게 텍스트만 바꾼다.
- 메인페이지에는 상단 고정 헤더와 홈 아이콘을 두지 않는다.

```text
[집] 연산 JSON 뷰어
[집] 문항뷰어
[집] section 뷰어
[집] 통계
```

`폴더 선택`, section 선택, `다시 읽기`, 파일 개수 표시 영역은 어느 페이지에서든 자유롭게 사용할 수 있도록 공통으로 유지한다.

### 다시 읽기 동작

`다시 읽기`는 현재 선택된 폴더를 다시 스캔하는 공통 동작으로 정의한다.

- 폴더를 아직 선택하지 않은 상태에서는 `다시 읽기` 버튼을 비활성화한다.
- 폴더를 한 번 선택한 뒤에는 `다시 읽기` 버튼을 활성화한다.
- `다시 읽기`를 누르면 기존에 선택된 폴더의 JSON 파일과 이미지 파일을 다시 불러온다.
- 메인페이지에서는 `다시 읽기` 버튼을 표시하지 않는다.
- 메인페이지에서 폴더가 선택된 상태로 `문항뷰어`, `section 뷰어`, `통계` 버튼을 누르면 해당 페이지로 이동하면서 자동으로 다시 읽기를 시도한다.
- 기능 페이지에서는 `R` 키를 누르면 현재 폴더를 다시 읽는다.
- 검색창, 입력창, 선택 상자에 포커스가 있을 때는 `R` 단축키를 실행하지 않는다.
- JSON이나 이미지 파일을 외부에서 수정한 뒤 화면에 반영할 때 `다시 읽기`를 사용한다.

첫 진입 상태:

```text
[연산 JSON 뷰어]
[?] [폴더 선택] [section 선택 비활성]
[문항뷰어] [section 뷰어] [통계]
```

폴더 선택 후:

```text
[연산 JSON 뷰어]
[?] [폴더 선택] [▼ 1 도형의 방정식]
[문항뷰어] [section 뷰어] [통계]
```

### 기능 이동 버튼

도구줄 아래에 세 개의 이동 버튼을 둔다.

- `문항뷰어`
- `section 뷰어`
- `통계`

각 버튼은 나중에 해당 기능 화면으로 이동하도록 연결한다.

## 예상 메인페이지 디자인 시안

### 시안 A: 기존 헤더 유지형

기존 뷰어의 상단 도구줄을 그대로 살리고, 본문 중앙에 기능 이동 버튼만 배치한다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [집] 연산 JSON 뷰어  [?] [폴더 선택] [▼ section 선택] [다시 읽기] 파일 0개 │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│                                                                              │
│                             연산 JSON 뷰어                                    │
│                                                                              │
│                    [ 문항뷰어 ] [ section 뷰어 ] [ 통계 ]                    │
│                                                                              │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

장점:

- 기존 작업물과 가장 자연스럽게 이어진다.
- 폴더 선택과 다시 읽기 위치가 모든 페이지에서 동일하다.
- 이후 문항뷰어, section 뷰어, 통계 페이지로 이동해도 헤더 구조가 흔들리지 않는다.

### 시안 B: 중앙 시작형

메인페이지에서만 제목과 도구줄을 중앙에 모아 보여준다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│                                                                              │
│                             연산 JSON 뷰어                                    │
│                                                                              │
│              [?] [폴더 선택] [▼ section 선택] [다시 읽기]                    │
│                                                                              │
│                    [ 문항뷰어 ] [ section 뷰어 ] [ 통계 ]                    │
│                                                                              │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

장점:

- 첫 화면이 메인페이지처럼 명확하게 보인다.
- 사용자가 처음 해야 할 일인 `폴더 선택`에 시선이 잘 간다.

주의점:

- 다른 페이지의 상단 헤더와 배치가 달라져 화면 이동 시 약간 다른 페이지처럼 느껴질 수 있다.

### 추천안

메인페이지는 `시안 B: 중앙 시작형`으로 구현한다.

이유:

- 메인페이지는 기능 진입 화면이므로 상단 고정 바보다 중앙 시작 화면이 더 명확하다.
- 첫 사용자가 해야 할 일인 `폴더 선택`과 페이지 이동 버튼이 한 화면 중앙에 모인다.
- 문항뷰어, section 뷰어, 통계 같은 실제 기능 페이지에서는 기존 상단 헤더 구조를 유지한다.

## 도움말 동작

도움말은 기존 작업물과 동일하게 모달창 방식으로 작동한다.

- `?` 버튼 클릭 시 현재 페이지 위에 도움말 모달을 표시한다.
- 모달이 열리면 배경은 어둡게 처리한다.
- 모달 오른쪽 위에 닫기 버튼을 둔다.
- 기존 작업물에 있던 닫기 동작이 있다면 그대로 유지한다.
- 도움말 내용은 우선 기존 내용을 임시로 사용하고, 이후 메인페이지와 각 기능에 맞게 수정한다.

## 페이지 분리 전제

현재 구상은 페이지를 실제 파일로 분리하는 방향을 전제로 한다.

예상 파일 구조:

```text
index.html
question-viewer.html
section-viewer.html
stats.html
```

GitHub Pages 배포를 고려해 링크와 리소스 경로는 상대경로를 사용한다.

```html
<a href="question-viewer.html">문항뷰어</a>
<a href="section-viewer.html">section 뷰어</a>
<a href="stats.html">통계</a>
```

## 아직 정하지 않은 항목

- `문항뷰어` 페이지의 실제 파일명
- `section 뷰어`에서 section을 어떤 기준으로 보여줄지
- 메인페이지 도움말 문구
- 메인페이지의 실제 색상, 여백, 버튼 크기
- 홈 아이콘의 실제 모양과 라벨 처리 방식
- 페이지 이동 시 선택된 폴더 정보를 어느 범위까지 유지할지

## 문항뷰어 매뉴얼 개편 기준

- 문항뷰어의 도움말 제목은 `문항뷰어 사용 매뉴얼`로 표기한다.
- 메인페이지 도움말과 분리해 문항 검수 작업 흐름만 설명한다.
- 처음 사용하는 순서는 `폴더 선택 → section 선택 → 문항 선택 → 내용·이미지 확인 → JSON/이미지 수정 → 다시 읽기(R) → 오류 확인`으로 안내한다.
- 왼쪽 문항 목록, 오른쪽 상세 화면, 검색과 필터, 이미지 확인, 단축키, 오류와 경고를 별도 섹션으로 나눠 설명한다.
- `메뉴얼` 표기는 `매뉴얼`로 통일한다.

## 좌측 문항 목록 기본 상태

- JSON 파일과 section 목록은 기본적으로 모두 접힌 상태로 표시한다.
- 사용자가 필요한 파일이나 section만 펼쳐서 확인한다.
- `전체 펼치기`, `전체 접기` 버튼으로 목록 상태를 한 번에 바꿀 수 있다.

## 통계 페이지 1차 기준

통계 페이지에는 section별 정답 개수 분포를 표시한다.

표 구성:

```text
파일 / subject / unit_large / unit_medium / unit_small / section_title / 문항수 / 1번 / 2번 / 3번 ...
```

- `subject`, `unit_large`, `unit_medium`, `unit_small`은 JSON 최상위 필드를 기준으로 표시한다.
- section 제목은 `[01] section_title` 형식으로 표시한다.
- 같은 파일에 속한 section 행은 파일 정보 셀을 첫 section 행에만 표시한다.
- 이미지가 있는 section 행은 연한 녹색으로 표시한다.
- 정답 번호 열은 실제 데이터에 나온 정답 번호를 기준으로 자동 생성한다.
- 기본적으로 `1번`부터 `5번`까지는 표시한다.

## 1차 성공 기준

- 상단 왼쪽 제목 옆에 집 모양 홈 아이콘이 보인다.
- 홈 아이콘을 누르면 메인페이지로 이동한다.
- 메인페이지 중앙에 `연산 JSON 뷰어` 제목이 보인다.
- 제목 아래에 기존 작업물과 유사한 도구줄이 보인다.
- 도구줄 아래에 `문항뷰어`, `section 뷰어`, `통계` 버튼이 보인다.
- `?` 버튼을 누르면 기존 작업물과 같은 방식의 도움말 모달이 열린다.
- 도움말 모달은 닫기 버튼으로 닫을 수 있다.
- 폴더 선택 전에는 `다시 읽기` 버튼이 비활성화된다.
- 폴더 선택 후에는 `다시 읽기` 버튼으로 현재 폴더를 다시 불러올 수 있다.
